## Non-obvious implementation points (so they aren't re-litigated)

`frontend/src/components/ImageLightbox.tsx` went through several iterations. The current design, and why, is documented in its own header comment and the bug ledger. Highlights:

- Gestures are plain React `onPointer*` handlers per slide — **no native listeners** (earlier native/capture approaches failed against Radix/embla). Zoom toggle lives in `pointerup`, not `onClick` (click re-fires with the freshly-fitted closure).
- Embla dragging is disabled while zoomed via the **`watchDrag` option**, relying on embla-react's auto-reInit; verified in embla source that reInit preserves the selected slide.
- `startIndex` is deliberately **not** in the watched options (reInit merges options *over* the preserved snap and would jump back to the first-opened slide); opening positions via an imperative `api.scrollTo(index, true)` in a `useLayoutEffect`.
- Escape is handled inside the dialog (`onEscapeKeyDown` preventDefault + `onKeyDown` + `stopPropagation`) so the sidebar's window-level Escape listener doesn't also fire.

## Dev-environment gotchas (cost real time this session)

- **PowerShell 5.1 strips `"` from native-exe args** — JSON bodies for `curl.exe` must go through `--data-binary @file`; a live E2E helper script exists at `C:\Users\windb\AppData\Local\Temp\opencode\vm3d-e2e.ps1` (not in the repo).
- **Chrome DevTools hides `console.debug`** by default (Verbose level) — use `console.log` for temp instrumentation.
- Seeded credentials are dev-only defaults (`SEED_ADMIN_*`, `SEED_DEMO_*`); see `backend/prisma/seed.ts` and `.env.example`. Do not treat as real secrets.
